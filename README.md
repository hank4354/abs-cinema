# abs(cinema)

Курсовой проект первого курса Московского Политеха. Это приложение для iOS, которое помогает выбрать фильм, сериал или мультфильм и разложить просмотренное и запланированное по спискам.

- Свайпы по карточке добавляют её в один из списков: «Хочу посмотреть», «Смотрел» или «Не хочу смотреть».
- В карточке можно открыть подробности. На экране статистики можно увидеть количество просмотренных позиций и их суммарную длительность.
- При запуске приложение показывает онбординг с подсказками по жестам. В настройках можно переключить тему.

Автор приложения — Хэнк Калашян. Всё приложение разработал самостоятельно.

## Как запустить

1. Откройте `abs(cinema).xcodeproj` в Xcode с установленным симулятором iOS 18 или новее.
2. Выберите схему `abs(cinema)` и симулятор iPhone.
3. Нажмите **Run** (⌘R).

Проект написан на Swift и SwiftUI. Каталог загружается из встроенных демонстрационных данных. Для загрузки постеров нужен интернет. Списки хранятся в памяти приложения и сбрасываются после его перезапуска.
